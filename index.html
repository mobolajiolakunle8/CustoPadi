Install & Launch CustoPadi

Add CustoPadi to your home screen

Put CustoPadi on your phone screen

On Android (Chrome): Tap the 3 dots ⋮ at the top right, then tap Add to Home screen (or Install app).

On iPhone (Safari): Tap the Share button at the bottom, then tap Add to Home Screen.

Share CustoPadi with other businesses

How to publish CustoPadi online for free

CustoPadi is a single file (index.html). You can host it free in 2 minutes:

  1. Netlify Drop (easiest): Put index.html inside a folder, go to app.netlify.com/drop, and drag the folder onto the page. You get a live https://...netlify.app link immediately.
  2. Vercel or Cloudflare Pages: Upload the folder at vercel.com or pages.cloudflare.com for a free custom link.
  3. GitHub Pages: Upload index.html to a GitHub repository and turn on Settings → Pages.
